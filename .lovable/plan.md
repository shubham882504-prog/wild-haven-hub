# Wildlife Sanctuary Website

## Goal
Create a warm, nature-led sanctuary website that helps visitors discover rescued animals, plan a visit, support conservation, and get in touch.

## Build
- Replace the placeholder home page with an immersive full-width sanctuary introduction and clear Donate and Visit Us actions.
- Add separate About, Animals, Visit, Get Involved, Events, and Contact pages with shared navigation and footer.
- Use the generated sanctuary and resident photography throughout the experience.
- Add mission and history content, conservation statistics, resident profiles, visitor hours and prices, map/directions, visitor rules, support options, event updates, contact form, social links, and newsletter signup.
- Create an earthy design system with forest green, warm clay, parchment neutrals, soft corners, generous spacing, and a clean sans-serif typeface.
- Add subtle reveal and hover motion while respecting reduced-motion settings.
- Make the navigation and all content fully usable on mobile.

## Interactions
- Mobile navigation opens and closes cleanly.
- Calls to action link to the relevant pages.
- Contact and newsletter forms provide clear confirmation after submission.
- Map and direction links open the sanctuary location in Google Maps.

## Validation
- Check every page at desktop and mobile sizes.
- Verify navigation, buttons, forms, images, metadata, and text fit without overlap.
