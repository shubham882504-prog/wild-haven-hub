# Wild Haven Hub

Create a modern, warm, nature-inspired website for a wildlife sanctuary. Include:

Hero section with a full-width image/video background, sanctuary name, tagline, and a "Donate" / "Visit Us" CTA button

About page section describing the sanctuary's mission, history, and conservation efforts

Animals/Residents gallery — grid of cards with animal photos, names, species, and short bios

Visit Us section with hours, ticket info, directions/map embed, and rules for visitors

Get Involved section covering volunteering, adoption/sponsorship programs, and donations

Events/News section for upcoming events, fundraisers, or blog-style updates

Contact form with name, email, message fields, plus social media links

Footer with quick links, address, phone, email, and newsletter signup

Design style: earthy color palette (greens, browns, warm neutrals), rounded soft edges, large nature photography, clean sans-serif typography, and generous whitespace. Fully responsive for mobile. Include smooth scroll animations and hover effects on cards/buttons.
